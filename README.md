# Rock Paper Scissors

A classic Rock Paper Scissors game built using HTML, CSS, and Vanilla JavaScript.

## Features

- **Interactive UI**: Playable move buttons (👊, 🖐️, ✌️) with smooth color transitions and scaling hover effects.
- **Score Tracking**: Automatically tracks and updates both player and computer scores across rounds in real-time.
- **Instant Result Detection**: Evaluates player choices against a randomized computer move to declare a win, loss, or tie.
- **Glassmorphism Design**: Centered translucent game card with custom borders overlaying a full-screen background.

## Play

Simply open `index.html` in your web browser to start playing!
